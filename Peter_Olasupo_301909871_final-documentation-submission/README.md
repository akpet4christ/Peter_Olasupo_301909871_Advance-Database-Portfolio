# MIT 8103 – Advanced Database Systems
## Final Submission Documentation

### Project Title
**Simulated MediLab Hospital Laboratory Information System**

### Project Overview
This folder contains the final documentation for my MIT 8103 Advanced Database Systems Continuous Assessment (CA) project.

The project involved designing, implementing, testing, and documenting a simulated hospital laboratory database system. The MediLab case study was used consistently across five practical portfolio activities to demonstrate my understanding of relational database design, query processing and optimization, transaction management, NoSQL databases, and distributed and cloud database concepts.

### Final Documentation

The following files are included in this folder:

1. **MIT8103_CA_Final_Documentation.docx** – The final Word document describing the case study, activities completed across all five portfolios, technical reflection, and AI use declaration.
2. **MIT8103_CA_Final_Documentation.pdf** – The PDF version of the final documentation for convenient viewing and submission.

### Portfolio Activities

The project consists of five practical activities:

- **Portfolio 1 – Database Design and Modelling:** Relational database design, entity relationships, primary and foreign keys, constraints, and normalization using PostgreSQL.
- **Portfolio 2 – Query Processing and Optimization:** SQL queries, execution plans, indexing, and query performance analysis.
- **Portfolio 3 – Transactions and Concurrency:** Transaction processing, COMMIT and ROLLBACK operations, isolation levels, and database locking concepts.
- **Portfolio 4 – NoSQL and Advanced Data Models:** MongoDB document modelling, CRUD operations, aggregation, validation rules, and indexing.
- **Portfolio 5 – Distributed and Cloud Database Exercise:** MongoDB replication, data synchronization, simulated sharding, consistency and availability concepts, and cloud database deployment using MongoDB Atlas.
