# Portfolio 5: Distributed and Cloud Databases

## Project Overview

This portfolio explores distributed database systems and cloud database technologies using the simulated MediLab Hospital Laboratory System.

The project focuses on understanding how databases distribute, replicate, and manage data across multiple servers and locations to improve availability, scalability, reliability, and performance.

## Objectives

- Understand distributed database concepts and architecture.
- Explore database replication and synchronization.
- Understand database sharding and horizontal scaling.
- Examine consistency and availability in distributed systems.
- Explore cloud database services and deployment models.
- Compare centralized and distributed database architectures.

## Tools and Technologies

- PostgreSQL 18
- MongoDB Community Server
- MongoDB Compass
- GitHub
- Cloud database concepts and services

## Practical Exercises

1. **MongoDB Replication:** Configured a single-node MongoDB replica set and verified its PRIMARY state.
2. **Database Synchronization:** Copied patient records between MongoDB databases and demonstrated manual synchronization.
3. **MongoDB Sharding:** Simulated horizontal data distribution across three collections and examined shard keys and scalability.
4. **Consistency and Availability:** Demonstrated stale data and manual reconciliation while studying consistency, availability, partition tolerance, and failover.
5. **Cloud Database Deployment:** Created a MongoDB Atlas cloud cluster, connected through MongoDB Compass and Mongosh, created a cloud database, and inserted and queried patient records.
6. **Cloud Database Technologies:** Compared MongoDB Atlas, Amazon DynamoDB, Azure Cosmos DB, and Amazon RDS, including their database models and use cases.
7. **Cloud Deployment Models:** Studied public cloud, private cloud, hybrid cloud, and multi-cloud deployment models.

## Key Learning Outcomes

Through this portfolio, I developed practical knowledge and understanding of:

1. **MongoDB Replication:** Configuring a replica set and understanding primary node operations, replication, and fault tolerance.
2. **Database Synchronization:** Transferring patient records between databases, verifying data integrity, and performing manual synchronization.
3. **Database Sharding:** Understanding shard keys, horizontal scaling, and distributed data storage.
4. **Consistency and Availability:** Understanding the CAP theorem, data consistency, availability, partition tolerance, and failover.
5. **Cloud Database Deployment:** Creating and accessing a cloud-hosted MongoDB database using MongoDB Atlas, Compass, and Mongosh.
6. **Cloud Database Technologies:** Comparing MongoDB Atlas, Amazon DynamoDB, Azure Cosmos DB, and Amazon RDS.
7. **Cloud Deployment Models:** Understanding public cloud, private cloud, hybrid cloud, and multi-cloud environments.
