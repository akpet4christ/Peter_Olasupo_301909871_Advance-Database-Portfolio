# MongoDB vs PostgreSQL

## Introduction

MongoDB and PostgreSQL are two popular database management systems. However, they use different data models and approaches to storing and managing information.

This document compares both systems using the simulated MediLab Hospital Laboratory System.

## 1. Database Models

**PostgreSQL**

PostgreSQL is a relational database management system (RDBMS). It stores data in tables consisting of rows and columns. Relationships between tables are established using primary keys and foreign keys.

**MongoDB**

MongoDB is a NoSQL document database. It stores data in flexible BSON documents organized into collections. Related information can be stored through embedded documents or references.
