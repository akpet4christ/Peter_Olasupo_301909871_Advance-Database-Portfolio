# Portfolio 1: Database Design and Modelling

## 1. Project Overview

This portfolio focuses on the design and implementation of a relational database for a simulated MediLab Hospital Laboratory System.

The project demonstrates practical database design concepts using PostgreSQL.

## 2. Case Study Description

MediLab Hospital Laboratory System is a simulated healthcare information system designed to manage laboratory operations within a hospital.

The system manages patient records, healthcare providers, laboratory test requests, laboratory staff, specimen collection, and test results.

## 3. Project Objectives

- Design a relational database for laboratory operations.
- Identify entities and their relationships.
- Develop an Entity Relationship Diagram (ERD).
- Implement database tables using PostgreSQL.
- Define primary keys and foreign keys.
- Apply database constraints.
- Demonstrate database normalization (1NF, 2NF, and 3NF).

## 4. Database Technology

- Database Management System: PostgreSQL 18
- Database Administration Tool: pgAdmin 4
- Version Control: Git and GitHub
